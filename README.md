# lammap

An interactive map of Finland's LAM traffic counting stations. Click or search for a station to see its traffic for the last 30 days. Data comes from [Fintraffic / Digitraffic](https://www.digitraffic.fi/) (CC BY 4.0).

The whole app is a single `index.html` with no build step.

**Live:** https://mlhollestelle.github.io/lammap/
